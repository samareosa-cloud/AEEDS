# 숨은그림찾기 자동 탐색 시스템

**Multi-Scale HOG 템플릿 매칭 + Coarse-to-Fine 탐색**

숨은그림찾기 퍼즐 이미지와 물체 템플릿(예시 그림)을 넣으면, 퍼즐 속 각 물체의 위치를 찾아 박스로 표시합니다.
학습 없이 HOG 특징과 코사인 유사도만으로 동작합니다.

> 건국대학교 전기전자심화설계및소프트웨어실습 기말 프로젝트 · C++ / OpenCV

## 결과

| 퍼즐 | 검출 | 성공률 |
|---|---|---|
| 퍼즐 A | 9 / 10 | 90% |
| 퍼즐 B | 15 / 20 | 75% |
| **전체** | **24 / 30** | **80%** |

- 9주차 얼굴 검출 코드를 그대로 적용했을 때는 퍼즐 A에서 0 / 10
- 탐색 시간 (나비 템플릿 1개 · 배율 3개 기준) : 68.6초 → 0.58초 (약 118배), 최종 검출 위치 동일

## 핵심 아이디어

| 문제 | 해결 | 관련 수업 |
|---|---|---|
| 물체 크기가 제각각 (40~100px) | 배율 피라미드 `s_k = 0.48 × 1.1^k` (10단계) | 2주차 크기 조절 |
| 탐색이 너무 느림 | 배율별 Gradient 재사용 + Coarse-to-Fine 2단계 탐색 | 9주차 슬라이딩 윈도우 |
| 좌우 반전 · 기울어진 물체 | 템플릿 반전 + Backward Mapping 회전 (±30°, 15° 간격) | 2주차 회전 |
| 비슷한 무늬에서 오검출 | 구별력 보정 `S′ᵢ = Sᵢ − λ · max_{j≠i} Sⱼ` (λ = 0.3) | 5주차 NNDR 아이디어 응용 |

## 처리 흐름

```text
입력 (퍼즐 이미지 + 물체 템플릿)
 → ① HOG 특징 추출   Prewitt, 9 bins, 48×48 창, 16×16 블록, stride 8 → 225차원
 → ② 후보 탐색       배율 10개 × 3px 간격 × (원본 + 반전) → NMS → 상위 5곳
 → ③ 정밀 탐색       후보 주변 ±4px, 배율 3개 × 각도 5개
 → ④ 최적 후보 선정   구별력 보정 후 물체마다 최고점
출력 (물체별 검출 위치)
```

- Gradient 크기 : `m′ = √(√(gx² + gy²))` (강한 에지 영향 완화)
- 유사도 : 코사인 유사도
- 회전 점수 보정 : `S − 0.01 × |θ| / 30°`

## 평가 방법

- 직접 만든 라벨링 도구(OpenCV 마우스 콜백)로 정답 위치와 크기를 저장
- 성공 기준 : `d ≤ 0.3 × max(w_g, h_g)` (d : 검출 중심과 정답 중심의 거리)

## 실행

```bash
g++ -std=c++17 -O2 hidden_search_distinct.cpp -o hidden_search $(pkg-config --cflags --libs opencv4)
./hidden_search
```

코드 위쪽의 `PUZZLE_DIR`, `TEMPLATE_DIR` 경로를 자기 폴더에 맞게 바꿔 주세요.


## 한계와 개선 방향

| 실패 원인 | 예 | 개선 방향 |
|---|---|---|
| 부분 가려짐 | 칫솔, 사과 | 부분 특징 비교 |
| 종횡비 차이 | 연필, 기타 | 직사각형 탐색 창 |
| 유사 패턴 | 카메라 | 다중 예시 기반 특징 학습 |

실패한 6개 모두 실제 위치의 유사도가 오검출 위치보다 낮았기 때문에, 탐색 범위를 넓히는 것보다 특징 표현과 비교 방식의 개선이 필요합니다.
