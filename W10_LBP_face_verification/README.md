# LBP 얼굴 검증 (웹캠, 자동 등록)

Haar로 얼굴을 찾고, 얼굴 LBP 히스토그램을 등록 얼굴과 비교해 같은 사람인지 판별한다. (macOS, OpenCV 4/5)

## 동작
1. 카메라 열기 → 프레임 가로 640으로 축소
2. Haar로 얼굴 검출 (최소 60×60)
3. **등록:** 30프레임 후 얼굴이 1개만 보이면 그 LBP를 기준으로 저장 (`enroll.bmp`)
4. **검증:** 이후 모든 얼굴의 LBP를 기준과 비교 → `score < th`면 초록(MATCH), 아니면 빨강

## LBP 특징 (`LBP.h`)
- 얼굴을 128×128로 resize
- 32×32 블록을 16픽셀씩 겹쳐 이동 → 7×7 = 49블록
- 블록마다 LBP 256-bin 히스토그램 → **49 × 256 = 12,544차원**
- `computeSimilarity`: 작을수록 비슷

## 코드 구조
| 함수 | 역할 |
|---|---|
| `loadCascade` | Haar xml을 현재 폴더 → Homebrew → OpenCV GitHub 순으로 찾기 |
| `openCamera` | 0~3번 카메라 중 검은 화면이 아닌 첫 카메라 사용 |
| `LBPdescriptor` | 얼굴 영역 → 12,544차원 히스토그램 |
| `computeSimilarity` | 등록/대상 히스토그램 비교 |
| `LBPimage` | LBP 이미지 확인용 창 |

## 이렇게 짠 이유
- **`raw` 복사:** 박스 그리기 전 원본에서 특징 추출 (선이 섞이지 않게)
- **30프레임 대기:** 카메라 노출·초점이 안정된 뒤 등록
- **얼굴 1개일 때만 등록:** 엉뚱한 사람 등록 방지
- **블록 겹치기(stride 16):** 블록 경계에 걸친 무늬도 잡기
- **xml 자동 탐색, OpenCV 5 대응:** 경로 수정 없이 어느 맥에서나 실행

## 키
`ESC`/`q` 종료 · `1` 재등록 · `+`/`-` 임계값 ±0.01

## 한계
조명·표정·각도에 민감. `th = 0.50`은 직접 보고 조정. 아이폰 연속성 카메라가 켜져 있으면 아이폰 카메라가 먼저 열릴 수 있음.
