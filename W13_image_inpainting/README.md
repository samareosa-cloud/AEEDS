# W13 - Image Inpainting (Text Removal)

OpenCV의 `cv::inpaint()`로 사진 위의 텍스트를 지우는 실습

1. 입력 사진을 불러와 800×600으로 크기를 맞추고
2. `putText()`로 사진에 "Hello Inpainting" 글자를 씀. --> 지울 대상 
3. 글자 영역을 흰색(255)으로 칠한 마스크(`textBox`)를 만듦.
4. `inpaint()`로 마스크 영역을 주변 픽셀로 채워 글자를 지움.


- 글자는 지워지고 주변 배경색으로 채워짐.
- `inpaint()`는 주변 픽셀의 가중평균으로 채우는 방식이라 복원 영역이 흐릿하게(blur) 보임.
- 마스크가 두꺼울수록(약 10~15px 이상) 흐림이 심해짐(FMM 방식의 한계)
