# W13 - Subtitle Removal using Corner Detection + Inpainting

Harris 코너 검출로 사진 속 자막 위치를 자동으로 찾고, `cv::inpaint()`로 자막을 지우는 실습

1. 입력 사진을 흑백으로 바꾸고 Harris 코너를 검출함.
2. 밝기 200 이상인 흰색 픽셀(자막 글자색)을 찾음.
3. 사진 아래 1/3 영역을 맨 아래 줄부터, 각 줄은 왼쪽에서 오른쪽으로 훑으면서 **흰 글자 위의 코너**를 찾음.
4. 찾은 코너들의 최소/최대 좌표로 자막 박스를 구함.
5. 자막 박스(+margin)를 마스크에 흰색(255)으로 칠함.
6. `inpaint()`로 마스크 영역을 주변 픽셀로 채워 자막을 지움.

- 자막은 획이 많이 꺾여서 코너가 빽빽하게 나오고 보통 흰색, 화면 아래쪽에 위치함.
- 그래서 아래쪽 + 흰색 + 코너 조건을 모두 만족하는 점을 자막으로 판단함.

- 박스 전체를 마스크로 쓰면 복원 영역이 커서(수백 px) 결과가 흐릿하게 뭉개짐.
- `inpaint()`가 주변 픽셀의 가중평균으로 채우기 때문.. 복원 영역이 두꺼울수록(10~15px 이상) 흐림이 심해지는 FMM 방식의 한계이다.
